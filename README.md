A fast drop-in for csv-reader 1.0.0: reads broken CSV files exactly as the reference does, faster. Records with no quote and no stray CR go through one native split; other fields are scanned with native indexOf / RegExp searches, and quoted spans are sliced whole unless they hold a line break.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The harness runs `node main.ts`, which reads every case from `/input/cases.json`, answers each with `run` from `solve.js`, and writes `/output/answers.json`.
